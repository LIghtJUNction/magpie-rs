# 未验证项和重建前需确认的内容

本文件记录无法从固定快照静态确认，或需要真实外部条件才能验证的部分。它不表示功能不存在。

## 本次没有做的验证

- 没有运行、构建或测试原始软件；没有用真实账户请求任何上游 Provider。
- 没有在 macOS、Windows、Linux、Docker 或 WSL 启动桌面/网关/浏览器/TUI，也没有用真实 Agent 校验配置 round-trip。
- 没有验证 OAuth/device-code/browser 登录、订阅续期、额度读取、插件安装/更新、WebDAV/S3/GitHub 写入、局域网或代理的线上行为。
- 没有测量性能、稳定性、并发、耗电、资源占用、TLS 安全、渗透安全或视觉可访问性。
- 没有独立重建 magpie，因此没有 REQ 实现率或兼容结论。

## 上游与账户依赖

- Agent 配置 schema、文件位置、版本检测、安装/更新和 MCP 支持会按 Agent 的 release、地区、企业版本、安装方式发生变化。构建时应锁定具体 Agent 版本并对真实配置做兼容验证。
- Provider presets、模型 id、输入输出能力、计价、限额、认证步骤、订阅 terms 和错误码随供应商更新。价格不能从静态截图推断为当前账单价。
- 社区插件的包版本和兼容性外部可变。`AGENTS.md` 中列出的 npm package/minimum version 说明来源边界，但不在本包内复制插件源码或证明包当前可安装。
- Gemini/Anthropic/Responses、音频、多模态和工具调用的跨协议映射需用有代表性的上游 payload 验证；文档列出支持面不等于所有字段可一一等价翻译。

## 基线中定义不完全或需独立验收的边界

- 系统密钥库在各 OS 的实际能力、锁屏/用户切换后的可读性、数据库加密和密钥迁移行为需要按目标平台检查。
- 本包中具体的权限、CSRF、Origin/Host、proxy 信任、SSRF/private-host、key scope、并发与失败验收在若干处是静态源码/安全原则推导出的重建目标；需用威胁模型和真实请求验证，不能据此宣称原版通过安全审计。
- 部分会话 title/session identity 来源依赖 Agent 自有数据库/会话文件格式和跨版本迁移；无可读 source 时只能显示未知。
- prompt masking 对图片、音频、视频、工具参数、供应商封装块和流式响应的真实覆盖面需逐协议确认；不能把文本匹配等同完整多模态遮蔽。
- 备份密钥格式/兼容迁移、并发 merge、损坏/回滚/Undo、多分片边界、限制最大数据尺寸均需用本地隔离 fixture 验证。
- 图中文字/状态数据是静态样例；截图不能精确回答布局断点、真实动画、可访问性树、所有本地化字符串及平台视觉差异。

## 建议重建验收准备

1. 冻结需要支持的 OS、Agent、Provider API 和插件版本矩阵。
2. 使用虚构账号、本地 HTTP fixture 和隔离 home 测试配置读写、协议转换、错误、密钥权限、备份回滚和多机冲突。
3. 依照 本配方根 BUILD_PROMPT.md 与 COVERAGE.md 的 REQ 清单逐项登记通过/失败/未运行，给出平台、输入、日志 request id 和原始观察。
4. 需要真实供应商/订阅才能确认的条目标记为“未运行”，不可用模拟 200 结果替代。


## Rust迁移新增待确认项

最低OS版本、真实目标设备、数值性能预算、插件精确协议schema、全部Agent版本矩阵与历史备份格式未确定。当前GPUI固定提交未提供Android原生后端；macOS原生SDK/Metal构建仍需真实Mac环境。Rust主实现和GPUI要求不允许无声改用其它框架来隐藏能力缺口。重复TOML key不能当合法输入强行往返：按目标Agent真实语法拒绝且保留原文件；REQ-013的该样例需按格式有效性解释。

文字视觉参考不能证明真实可访问性/动画；其颜色和密度是观察性指导，无精确token或动画时间数据。原版静态截图包含的品牌账号/额度数据不作为产品默认数据。
