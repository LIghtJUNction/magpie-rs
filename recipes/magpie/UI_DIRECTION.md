# 当前桌面视觉与交互方向

用户已明确否决此前暖白/深墨绿、名录/详情式设计，并要求“不得比原版丑”，由 Pro 重新美化。此前 UI revision 1、UI actions revision 1，以及统一列表的 visual revision 2 均未获认可；用户最新再次要求由 Pro 改样式，并明确功能也要一比一还原。构建/组件/字体检查通过只说明相应技术路径，视觉验收均未通过。全部 93 条需求及 Rust/GPUI 约束继续有效。

## 原版作为最低视觉基线

- 以 `magpie-interfaces/UI_REFERENCE.md` 的原版文字参考和已核验公开静态截图作为对照；浅色/深色都要比较，禁止仅凭“现代”“高级”等形容词判定达标。
- 日常主页面以可扫读的 Agent 行列表为中心：图标/身份、当前模型、真实配置归属和可执行动作应清楚对齐。模型选择尽量在行内完成，连接设置、变更预览及恢复确认按需打开。
- 路径、原始字段、程序位置和技术说明放入可展开诊断区，默认页面不再被名录和大详情表单占满。保持适度密度、统一字号/基线/间距、克制边框和圆角。
- 以原版白灰/炭黑材质、小面积强调色和清楚层级为参照，重新交付实际颜色 token；旧暖白/深墨绿方案不再作为已接受方向。
- 正文、控件和标题使用经过实际解析验证的无衬线字体，覆盖中文/日文和德文。GPUI 字体名按固定版本 API 与平台验证，不能把 CSS fallback 列表当作原生字体族名。
- 当前只展示已实现的入口与真实状态。完整产品仍须提供全部导航与功能，不能用虚构模型、账户、余额、连接开关或空壳页面美化截图。

## 已实现交互必须保留

- 保留真实 CLI 模型查询、搜索/稳定 ID 选择、只读预览、显式保存、配置归属重读和离线恢复。预览绑定路径/地址/模型/配置观察，变化后重新预览；重复操作、取消和不确定结果仍正确处理。
- 未设置字段明确显示未设置；安装检测不表示在线，configured 目录不表示 Provider 已可服务。失败保留输入，漂移和恢复错误可辨认。
- 宽窗、900×560、360/440px 窄窗均保持任务可达；选择/复制对象按稳定 Agent ID 保留。弹层可退出，焦点返回触发位置，滚动与键盘可达。
- 五语、系统/深浅主题、CJK 输入、IME、Enter/Space 单次触发、Tab/焦点、读屏和 reduce motion 等完整要求保留。

## 视觉验收

Pro 交付原版/旧方案/新方案的同尺寸对照，以及浅色、深色、窄窗、选模、预览、保存中、失败、漂移和长名称的实际渲染。设计稿明确标注合成数据，不冒充原生截图。

先审查对照和字体，再原生构建并检查实际窗口；编译、组件测试、HTML 预览、原生视觉检查和用户认可分开记录。用户明确认为新界面不逊于原版前，不把视觉标成通过，也不将此前设计当作桌面发行验收结果。

## 标准库依赖与具体取舍

本轮按更新后的迁移/重写流程复用 `design-directions` 固定提交 `6fdba350d1effa2d50dc0185095bb91ca7a699ee`，递归 `design-foundations` 固定提交 `8c5bf1f1e40719789cf51bc0dfd8f5aeecae0538`。已读取两包全部构建、方向、视觉、交互、可访问性、评估、验收与来源材料；两包没有独立 COVERAGE.md 或 LICENSE 文件，不能编造授权或覆盖结论。当前集成是配方引用与归档材料收集，发布授权记录仍需明确；不复制参考产品图标/字体/商标资产。

作用范围为 GPUI 主窗/托盘面板、Web/TUI 的导航、内容密度、状态反馈、响应式、键盘与恢复流程；CLI 仅使用适用的信息层级、错误文案和反馈规则，不要求图形界面。

- 选择“高密度工作台 + 平台原生体验”：Agent 行直接显示当前模型、配置归属和可执行接入；Provider/模型管理、路由和 Usage 以真实数据组织。中窗跟随原版顶部导航，宽窗遵守 REQ-101，窄窗重排保留任务。统一语义 token 与常规无衬线字体，不增加装饰性大卡片。
- 可行备选是“任务导向服务”：适用于首次添加 Provider、导入、连接确认和恢复向导，但把整套日常界面做成逐步向导会增加高频切模成本，因此仅用于相应局部流程。
- Usage 采用“数据分析”的口径规则：单位、时段、未知值/估算、最终请求与尝试分别表达；未实现的数据不填零或假图。Library 帮助内容可采用阅读式行宽，不改变编辑/分发行为。

实现与验收必须检查空/加载/保存中/失败/长内容、并发更新、取消后重读、焦点返回、五语、文本放大和减少动效。Web 目标标准与原生辅助技术分开记录；不得把几个对比度值或截图当成全量无障碍通过。真实 GPUI Scene 导出只证明该 fixture 的像素，实际窗口交互、IME、读屏和用户视觉认可仍独立验收。当前仅完成依赖与设计合同集成，未因此提升任何功能或视觉完成状态。
